# Dataset no publicado

Este repositorio público no incluye el archivo `dataset_fuente.csv` ni las salidas derivadas. Antes de reproducir el análisis, verifique la fuente, los permisos y la licencia específica del dataset, y ubique una copia autorizada en `datos/dataset_fuente.csv`.

No se debe confundir la ausencia del dataset con pruebas completas y reproducidas en GitHub Actions. El workflow ejecuta únicamente comprobaciones estructurales que no necesitan los registros originales.
